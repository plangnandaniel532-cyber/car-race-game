# 🏎️ PLATEAU RACE - Car Racing Game

A fast-paced, mobile-friendly car racing game built by **Daniel Plangnan from Plateau State, Nigeria**.

### 🎮 How to Play
- Steer with ◀ ▶ buttons
- Dodge red enemy cars
- Score increases as you survive
- Speed gets faster!
- Works on phone, tablet & PC

### 🚀 Built With
- HTML5 Canvas
- CSS3
- JavaScript
- Built 100% from my phone!
- No downloads needed — play directly in your browser!
